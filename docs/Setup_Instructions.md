# Setup Instructions

## JDK version

This project targets **Java 17**. Verify with:

```text
java --version
javac --version
```

## IDE

Open the project folder in IntelliJ IDEA (or another IDE) and let Gradle sync.

## Hello World

Create a small class with `public static void main(String[] args)` that prints `Hello, World!`, run it from the IDE or compile with `javac` and run with `java`. Attach a screenshot for your submission if required.

The LearnTrack entry point is `com.airtribe.learntrack.ui.Main` (see project `README.md`).
